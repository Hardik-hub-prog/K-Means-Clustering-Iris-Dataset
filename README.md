# K-Means-Clustering-Iris-Dataset
K-Means clustering on the Iris dataset using Elbow Method and Silhouette Score to determine optimal K and visualize clusters.
🎯 Objectives
Understand the working of the K-Means clustering algorithm.
Determine the optimal number of clusters using the Elbow Method.
Validate the optimal K using the Silhouette Score.
Apply K-Means clustering to the Iris dataset.
Visualize the identified clusters.
